# ASTB-2.0-3.0
台湾有事のリスクを低減します。
2.0でチャイナの不良債権から来る金融危機を取り除き、3.0でそのことが台湾有事を無意味化することを説明します。
チャイナを強くしすぎることはありません。
台湾有事が起こらなかった場合、ASTB（アジア金融安定化・エネルギー転換銀行）構想のおかげかどうか証明不能ですが、保険とはそういうものです。
それだけではなく、「エネルギー転換銀行」により、チャイナのみならず、アジア全体の脱炭素化を図ります。ひいては、世界全体のそれをもくろんでいます。
日本の負担金が高いような気もしますが、チャイナ発の金融危機（リーマンショックの3-5倍とも）や台湾有事で吹っ飛ぶ金に比べれば、安い保険料です。
ASTBは、石油枯渇・チャイナ発の世界恐慌・台湾有事に対応した巨大な構想です。
2.0は読みにくい構成になっておりますが、最初に真ん中あたりまでスクロールダウンして読み始め、下まで読み終えたら一番上までスクロールアップしてください。
